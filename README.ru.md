# MOAI Studio 21 🗿🎛️

**MOAI Studio 21** — несерьёзный проект для Discord Rich Presence от команды **JVR_Prod**, в которой пока один разработчик. Цель простая: чтобы в профиле было что-то интереснее, чем просто «В сети», а MOAI спокойно делал свой BRrrrAM BAM BAM BA-Bam.

## Что такое MOAI Studio 21?

Это шуточный проект, вдохновлённый названием **FL Studio 21**, мемами о музыкальном продакшене и реакцией 🗿 MOAI: лицо каменное, решения сомнительные, вайб безупречный.

Число «21» — отсылка к FL Studio 21. **MOAI Studio 21 — независимый пародийный проект, не связанный с Image-Line или FL Studio и не одобренный ими.** Проект также не связан с Discord.

Мы не пытаемся создать новую DAW, которая перевернёт музыкальную индустрию. Задача куда серьёзнее: добавить смешную кастомную активность в профиль Discord. Если MOAI счастлив — микс готов. Если мастер клиппует — MOAI всё равно спокоен.

## Как это работает

MOAI Studio 21 использует Discord Rich Presence как идентификатор и конфигурацию отображаемой активности. Rich Presence позволяет совместимой программе передавать сведения об активности запущенному настольному клиенту Discord.

1. **Идентификатор приложения.** Проект зарегистрирован в Discord Developer Portal и имеет Application ID. Изображения для активности можно загрузить в ресурсы приложения.
2. **Локальный RPC-клиент.** На компьютере запускается совместимый клиент Rich Presence. Он формирует текст активности, временные метки и ключи изображений.
3. **Локальное соединение.** Клиент взаимодействует с настольным Discord через локальный RPC-интерфейс (IPC).
4. **Discord показывает активность.** Discord отображает полученные данные и изображения с учётом собственного поведения и настроек приватности пользователя.
5. **Выключение режима MOAI.** Когда RPC-клиент сбрасывает активность или прекращает её обновлять, кастомная активность больше не поддерживается.

**Без магии:** Application ID — это идентификатор, а не исполняемый файл. Переименование приложения в Developer Portal не создаёт RPC-клиент. В этом репозитории находятся сайт проекта, юридические страницы и документация; **самостоятельного настольного приложения или RPC-клиента здесь нет**.

## Продакшен-процесс MOAI

- Открой Discord.
- Запусти совместимый клиент Rich Presence.
- Укажи поля активности, например:
  - **Details:** `MOAI is cooking the 808`
  - **State:** `Sidechain? I hardly know her`
  - **Подпись изображения:** `Certified boulder moment`
- Посмотри на карточку профиля так, будто Reddit уже написал «this goes hard».
- Если мастер красный, это не новый метод мастеринга. Наверное.

## Конфиденциальность и данные

Этот репозиторий содержит статический сайт. В нём нет собственной системы аккаунтов, серверной части приложения или аналитики. В предполагаемой конфигурации Rich Presence локальный RPC-клиент передаёт Discord данные активности, чтобы тот мог показать их в профиле. Discord обрабатывает эти данные по собственным условиям и политике конфиденциальности.

У сторонних RPC-клиентов могут быть собственные разрешения, журналы, телеметрия и правила обработки данных. Этот репозиторий ими не управляет — проверяй программу, которую выбираешь. Политика конфиденциальности верна только пока проект самостоятельно не собирает и не хранит персональные данные через собственный сервер. Если это изменится, сначала обнови политику.

## Публикация через GitHub Pages

1. Создай **публичный** репозиторий GitHub, например `moai-studio-21`.
2. Загрузи `index.html`, `terms.html` и `privacy.html` в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохрани настройки.
5. Дождись публикации и проверь, что все страницы открываются без входа в GitHub.
6. Вставь адреса `terms.html` и `privacy.html` в соответствующие поля Discord Developer Portal → **General Information**.

Ссылки будут выглядеть так (замени `YOUR-GITHUB-USERNAME` на свой логин GitHub):

- `https://YOUR-GITHUB-USERNAME.github.io/moai-studio-21/`
- `https://YOUR-GITHUB-USERNAME.github.io/moai-studio-21/terms.html`
- `https://YOUR-GITHUB-USERNAME.github.io/moai-studio-21/privacy.html`
